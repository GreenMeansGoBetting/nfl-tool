    Team Grades

    Passing/Rushing/Red Zone grade OFF as this team's own production and DEF as what the opposing defense allows, same as every table above. Scheme is the only category built from BOTH sides at once: its OFF grade is how well this team's own offense performs against the varied looks (blitzes, coverages, box counts) it faces league-wide, and its DEF grade is how well this team's own defense executes when it calls those same varied looks -- so a team's Scheme OFF and DEF grades describe two different units, not the same one twice.
